# Seed Library Grow Guide

A lightweight front-end prototype for the Point St Charles idea: a local seed and garden tool helper that lowers the barrier to food gardening.

## Features

- Pick a known seed from a local list or type your own seed.
- Generate a grow plan with:
  - equipment recommendations
  - space needs
  - effort level
  - water + light guidance
  - rough growth timeline
- Add a target planting date and get reminder milestones.
- Highlights local library support resources (tool lending, grow lights, seed borrowing).

## Run locally

Open `index.html` in a browser, or serve with a basic local server:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.
